Tools

cloudflare-developer-platform_list

List records for an entity.

{
  "type": "object",
  "required": [
    "entity"
  ],
  "properties": {
    "entity": {
      "type": "string",
      "description": "app | artifact | bill_subs_api_bulk_account_subscription | brand_protection | changelog | flag | flagship_evaluation_result | flagship_flag_definition | monolith_health | zone_snippet"
    },
    "query": {
      "type": "object",
      "description": "Optional match fields for the selected entity."
    }
  }
}

Supported entities: app, artifact, changelog, flag, monolith_health, zone_snippet.

cloudflare-developer-platform_load

Load one record for an entity.

{
  "type": "object",
  "required": [
    "entity"
  ],
  "properties": {
    "entity": {
      "type": "string",
      "description": "app | artifact | bill_subs_api_bulk_account_subscription | brand_protection | changelog | flag | flagship_evaluation_result | flagship_flag_definition | monolith_health | zone_snippet"
    },
    "query": {
      "type": "object",
      "description": "Optional match fields for the selected entity."
    }
  }
}

Supported entities: app, artifact, brand_protection, flag, flagship_evaluation_result, flagship_flag_definition, zone_snippet.
