Set up the client

This setup fragment reads credentials from the environment. Use the API operation reference to supply input for each call.

require_relative "CloudflareDeveloperPlatform_sdk"
client = CloudflareDeveloperPlatformSDK.new({"apikey" => ENV["CLOUDFLARE_DEVELOPER_PLATFORM_APIKEY"]})
